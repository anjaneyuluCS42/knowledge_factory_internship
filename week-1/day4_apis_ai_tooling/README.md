# EST API

REST API stands for Representational State Transfer.

REST APIs allow communication between:
- Client
- Server

Features:
- Stateless
- Uses HTTP methods
- Uses JSON format

Workflow:
Client → HTTP Request → Server → JSON Response

# Postman Basics

Postman is an API testing tool.

Uses:
- Send API requests
- Test APIs
- View JSON responses
- Check status codes
- Debug APIs

# Methods Practiced:
- GET
- POST
- PUT
- PATCH
- DELETE

# Status Codes

200 → Success
201 → Created
400 → Bad Request
401 → Unauthorized
403 → Forbidden
404 → Not Found
500 → Internal Server Error
