# 🌍 Country Intelligence Dashboard

A modern enterprise-level Country Intelligence Dashboard built using FastAPI, REST Countries API, and Ollama Cloud AI.

This application provides professional country insights including:
- Country Flag
- Capital
- Currency
- Population
- Languages
- Literacy Rate
- GDP Ranking
- National Sport
- Male/Female Population Percentage

The project is designed with a responsive modern UI inspired by top-tier MNC product dashboards.
