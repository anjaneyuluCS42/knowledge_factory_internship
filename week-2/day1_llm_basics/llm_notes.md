# LLM Notes

## What is an LLM?

LLM stands for Large Language Model.

Large Language Models are AI systems trained on huge amounts of text data such as:
- Books
- Websites
- Articles
- Documentation

LLMs generate human-like text by predicting the next word in a sentence.

Examples:
- GPT
- Gemma
- Llama
- Claude

# What are Tokens?

LLMs process text as tokens.

Example:
Sentence:
"I love AI"

Tokens:
- I
- love
- AI

Tokens are important because:
- Pricing depends on tokens
- Memory depends on tokens
- Long prompts use more tokens

---

# What is Temperature?

Temperature controls creativity in AI.

Low Temperature:
- More accurate
- Less creative

High Temperature:
- More creative
- More random

Example:
- Coding → Low temperature
- Story writing → High temperature

---

# What is Context Window?

Context Window is the amount of information an AI can remember in a conversation.

Larger context windows help:
- Long chats
- File understanding
- Better memory handling

# Ollama Basics

Ollama helps run AI models locally on a computer.

Advantages:
- Offline usage
- Better privacy
- Local AI development

Example:
