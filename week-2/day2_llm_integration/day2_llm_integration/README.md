# Day 2 - LLM Integration using Python

## Overview

This project demonstrates how to integrate Large Language Models (LLMs)
with Python applications using OpenAI APIs and Ollama local models.

---

## Topics Covered

- OpenAI API Integration
- Ollama Local LLM Integration
- Streaming Outputs
- Prompt Chaining
- AI Chatbot Development

---

## Technologies Used

- Python
- OpenAI API
- Ollama
- Llama3

## File Descriptions

### openai_basic.py
Basic integration with OpenAI API.

### ollama_basic.py
Local LLM integration using Ollama.

### streaming_output.py
Demonstrates real-time streaming responses.

### prompt_chaining.py
Shows how outputs from one prompt can be used in another.

### chatbot.py
Simple AI chatbot with conversation memory.
